Step-by-Step Local Setup
1

Install Prerequisites

Download and install XAMPP (includes PHP + MySQL + Apache) and Git.

# Download from:
https://www.apachefriends.org # XAMPP
https://git-scm.com # Git
https://code.visualstudio.com # VS Code (recommended editor)
2

Clone the Repository

Open a terminal (or Git Bash on Windows) and run:

# Navigate to XAMPP web folder
cd C:/xampp/htdocs # Windows
# cd /Applications/XAMPP/htdocs # Mac

# Clone the repo
git clone https://github.com/phoenix-2code/faithx-infinity-version-two.git faithx

# Enter the folder
cd faithx
3

Create the Database

Start XAMPP, open http://localhost/phpmyadmin, create a new database named faithx_db, then import your SQL schema file.

# In phpMyAdmin:
1. Click "New" in left sidebar
2. Name it: faithx_db
3. Collation: utf8mb4_unicode_ci
4. Click "Import" tab → choose your .sql file
4

Configure Database Connection

Edit config/database.php with your local credentials:

<?php
$host = 'localhost';
$dbname = 'faithx_db';
$username = 'root'; // XAMPP default
$password = ''; // XAMPP default (empty)

try {
  $pdo = new PDO("mysql:host=$host;dbname=$dbname;charset=utf8mb4", $username, $password);
  $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
  $pdo->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);
} catch (PDOException $e) {
  die('DB connection failed: ' . $e->getMessage());
}
5

Visit & Test

Open your browser and go to http://localhost/faithx/. Register a new account, login, and test all 3 core features.

# Test URLs:
http://localhost/faithx/ # Home
http://localhost/faithx/index.php?page=register # Register
http://localhost/faithx/index.php?page=pledges # Create pledge
http://localhost/faithx/index.php?page=payments # Record payment
6

Push Changes Back to GitHub

After making improvements, push back to your repo:

git add .
git commit -m "improve: security, performance, UI cleanup"
git push origin main

Overpayment Guard — Add to payment_actions.php
// Add BEFORE inserting the transaction:

// Get pledge amount and current total paid
$stmt = $pdo->prepare("
  SELECT p.amount,
  COALESCE(SUM(t.amount_paid), 0) as already_paid
  FROM pledges p
  LEFT JOIN transactions t ON p.pledge_id = t.pledge_id
  WHERE p.pledge_id = ?
  GROUP BY p.pledge_id
");
$stmt->execute([$pledge_id]);
$pledge = $stmt->fetch();

if (!$pledge) throw new Exception('Pledge not found.');

$remaining = $pledge['amount'] - $pledge['already_paid'];

if ($amount_paid > $remaining) {
  throw new Exception('Payment exceeds remaining balance of KSh ' . number_format($remaining, 2));
}

Loading State for Buttons (JS)
// Add this to assets/js/main.js — prevents double-submit on all API forms

function setLoading(btn, loading) {
  if (loading) {
    btn.disabled = true;
    btn.dataset.original = btn.innerHTML;
    btn.innerHTML = '<span class="spinner-border spinner-border-sm me-2"></span>Processing...';
  } else {
    btn.disabled = false;
    btn.innerHTML = btn.dataset.original;
  }
}

// Usage — in any form submit handler:
const submitBtn = document.getElementById('submitPledgeBtn');
setLoading(submitBtn, true);
// ... after fetch resolves:
setLoading(submitBtn, false);
